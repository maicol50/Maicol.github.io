Uno de los proyectos de mi experiencia en desarrollo es un sistema de gestión de recursos humanos y dietas. En él participé en tareas de backend y frontend, conectando la lógica de la aplicación con interfaces administrativas.

## Backend y lógica de negocio

Trabajé con PHP 8 y Laravel 12 para construir módulos web y aplicar patrones de arquitectura y lógica de negocio.

## Paneles administrativos

Utilicé Filament para crear interfaces administrativas, formularios dinámicos y componentes para gestionar relaciones entre datos.

## Organización del trabajo

También utilicé Git para el control de versiones y colaboré con la documentación técnica del proyecto. Esta experiencia reúne varias áreas que sigo desarrollando: programación backend, desarrollo web y trabajo con bases de datos relacionales.
